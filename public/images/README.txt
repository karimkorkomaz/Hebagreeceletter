Drop her photos in this folder with these exact names:

  heba.jpg     -> goes inside the plane window. Use a SQUARE close-up of
                  her face. It renders tiny (about 25px), so crop tight —
                  head and shoulders only, nothing wider.

  photo-1.jpg  -> first photo in the letter
  photo-2.jpg  -> second photo in the letter

The letter photos are cropped to a 4:5 portrait shape, so portrait
orientation works best.

.png works too — just change the filename in index.html to match.

Any photo you don't add shows a dashed placeholder instead of a broken
image, so nothing looks wrong while you're still deciding.

Keep each file under ~500 KB so it loads fast on her phone data.
